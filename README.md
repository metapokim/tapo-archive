# TAPO’s archive

은유 님의 개인 스크랩 아카이브 — 학회·포럼, 대학원·논문, 기사·뉴스레터, 공연·전시(2026년 기록), 책, 메모를 한 장에 모은 페이지.

- 웹 주소: https://metapokim.github.io/tapo-archive/
- 원본 파일: `index.html` (단일 파일, 외부 리소스 없이 동작)
- 내용 수정은 `index.html`을 고쳐 커밋·푸시하면 바로 반영됩니다.
- 메뉴 순서: 전체 · 학회·포럼 · 대학원·논문 · 기사·뉴스레터 · 공연·전시 · 책 · 메모
- 메모: 제목(선택)·본문을 적어 저장하고, 카드의 `메모 앱으로 보내기`로 아이폰 공유 시트 → 메모 앱에 넘깁니다.
- 기기 간 동기화: 상단 ☁️ 버튼 → GitHub 토큰(`gist` 권한)과 Gist ID를 넣으면, 바뀐 내용만 비공개 Gist(`tapo-archive-sync.json`)에 자동 저장되고 다른 기기와 `updatedAt` 기준으로 합쳐집니다. 토큰은 그 기기의 브라우저(localStorage)에만 남습니다.
