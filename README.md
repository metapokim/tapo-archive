# TAPO’s archive

은유 님의 개인 스크랩 아카이브 — 학회·포럼, 대학원·논문, 기사·뉴스레터, 영상·기타자료, 공연·전시(2026년 기록), 책, 메모를 한 장에 모은 페이지.

- 웹 주소: https://metapokim.github.io/tapo-archive/
- 원본 파일: `index.html` (단일 파일, 외부 리소스 없이 동작)
- 히어로(모닝 브리핑 + 다가오는 일정)는 `전체` 메뉴에서만 보입니다. `학회·포럼`·`대학원·논문`·`기사·뉴스레터`·`영상·기타자료`·`공연·전시`·`책`·`메모`를 고르면 `.hero`를 통째로 접어(스크립트가 `hidden` 지정, `[hidden]{display:none!important}`) 그 메뉴의 필터·카드 목록이 바로 시작됩니다 — PC·아이패드·아이폰 같은 규칙이고, 접힌 자리에 필터 줄을 12px 띄웁니다(`.hero[hidden] + .filters`). `다가오는 일정` 줄을 눌러 카드로 이동할 때도 히어로가 접힌 상태에서 해당 탭 전환·필터 해제·카드 스크롤·반짝임이 그대로 동작합니다. 페이지를 새로 열면 늘 `전체`로 시작하므로(카테고리는 저장하지 않음) 첫 화면에는 히어로가 보입니다.
- 다가오는 일정 카드: 데스크톱·아이패드 가로(>900px)에서 브리핑 카드와 폭·높이를 똑같이 맞추고(`1fr 1fr`, 공통 높이 `--hero-h`), 목록이 카드 하단까지 차면서 남는 만큼만 카드 안에서 스크롤합니다(스크롤바는 감춤, 끝까지 내리면 아래 흐림이 사라짐). 줄을 누르면 해당 카테고리 탭으로 바뀌고 필터를 풀어 그 카드로 스크롤·반짝임 표시하며, 캘린더에서 온 일정은 '네이버 캘린더 전용 일정' 안내만 뜨뜸니다.
- 브리핑 할 일 목록: 라벨·날씨 요약과 입력창·날씨 출처 줄은 카드에 고정되고, 가운데 할 일 목록(`.brief-scroll` — 아침 루틴 항목 + 직접 추가한 할 일)만 카드 안에서 스크롤합니다. 그래서 할 일을 여러 개 더해도 카드 높이가 늘지 않고 `다가오는 일정`과 계속 같은 높이입니다. 스크롤바는 양쪽 다 숨기고 터치·휠로만 움직입니다. 루틴이 `MORNING_BRIEF_START~END`를 갈아끼우며 `.brief-scroll` 상자를 빠뜨려도 스크립트가 목록을 다시 감싸 줍니다.
- 아침 브리핑 카드 제목은 `TODAY'S BRIEFING`, 오른쪽 날짜는 `11월 16일 월` 형식으로 스크립트가 지금 시각(`new Date()`)을 넣어 채웁니다. 페이지를 켜 둔 채 자정을 넘겨도 다음 `00:00:01` 타이머가 날짜와 아래 발행 기준 줄(`issueLine`)을 다시 맞추고, 아이폰에서 앱을 다시 열 때(`visibilitychange`·`focus`·`pageshow`)도 한 번 더 맞춥니다. `.brief-when`의 `datetime` 속성은 브리핑을 쓴 시각 그대로 두어 완료 체크 기록의 날짜 키가 흔들리지 않습니다.
- 브리핑 첫 줄 날씨도 날짜를 따라갑니다: 아침 루틴이 `.brief`의 `data-weather-days`에 오늘·내일 두 날짜(`"YYYY-MM-DD"`)의 `오늘(요일) 서울은 <b>…</b>` 문구를 JSON으로 넣어 두면, 화면이 뜰 때·자정(`00:00:01`)·다시 열 때 그 날짜 문구로 `.brief-lead`를 바꿔 어제 날씨가 남지 않습니다(스크립트 안 `WEATHER_FALLBACK`에 2026-11-17·18 문구가 안전망으로 하나 더 있습니다). 그 날 문구가 없으면 요일만 오늘로 고칩니다 — `오늘(월)`이 남는 일은 없습니다.
- 브리핑 할 일 순서 바꾸기: 항목을 아이폰에서는 350ms 길게 누른 뒤, 데스크톱에서는 마우스로 끌어 위아래로 옮기면 그 자리에 그대로 끼워집니다(끄는 줄은 살짝 확대·레몬 테두리, 위·아래 끝에서는 상자가 따라 스크롤). 톡 누르면 예전처럼 완료 체크, `×`는 삭제 그대로입니다(끌고 난 직후 450ms 클릭은 삼킴). 순서는 `brief.order`(`list`에 `s|시각 문구`·`m|할일id`, `at`은 마지막 변경 시각)로 기기 저장소에 남고 Gist 동기화 `brief`에도 실려 다른 기기와 `at`이 큰 쪽으로 합쳐집니다. 루틴이 목록 HTML을 갈아끼워도 같은 문구면 순서가 이어지고, 직접 추가한 할 일도 같은 목록(`.brief-list`)에 함께 그려집니다(시각 순서를 목록 줄과 나란히 세우려고 2026-11-18에 `.brief-mine`을 화면에서 뺐습니다 — 요소는 남아 있어 저장본·동기화 호환은 그대로입니다).
- 시간 있는 일정은 늘 맨 위에서 이른 순(2026-11-18, PC·아이패드·아이폰·위젯 모두): 기본 일정(`brief-time` = `14:00`)과 시각을 골라 넣은 할 일을 한 목록에 그린 뒤, **시각(`HH:MM`)이 있는 줄을 맨 위에서 오름차순**으로 세우고 시각 없는 줄은 그 아래에 기존 차례대로 둡니다(`sortBriefByTime()` — `renderBrief()` 끝에서 `applyBriefOrder()` 다음에 한 번). 그래서 끌어서 정해 둔 순서(`brief.order`)가 시각 항목을 아래로 밀어도 시각 순서가 마지막에 이기고, 시각 있는 줄을 끌면 제 시각 자리로 돌아갑니다(토스트 `시각 있는 할 일은 시각 순서로 놓입니다`). 시각 없는 줄끼리의 차례는 지금처럼 `brief.order`를 따릅니다. 위젯(`buildModel`)도 같은 규칙을 씁니다.
- 오늘 목록에 이미 있는 문구(예: `12:30 건우`, `18:00 콩지 연고 발라주기`)를 직접 추가한 할 일에도 또 넣어 두면 두 줄로 보이므로, 화면이 뜰 때 같은 문구(시각·`할 일` 라벨은 떼고 비교)의 사본을 지웁니다(지운 표시 `todoDel`을 남겨 다른 기기 사본이 되살리지 못하게). 문구가 달라도 같은 일은 `BRIEF_TODO_SAME` 별칭으로 묶습니다(`건우 만나기` → `건우`). 목록에서 그 줄이 사라진 날 이후에는 손대지 않습니다.
- 아침 브리핑: 각 항목 왼쪽 원형 버튼을 누르면 오늘 목록에서 사라집니다. 체크 기록은 `날짜|문구` 키로 이 기기(localStorage)와 Gist 동기화에 함께 남아 다른 기기에도 적용되고, 날짜·문구가 바뀌면 새 브리핑과 섞이지 않습니다. 되돌리기는 뜨는 토스트나 상단 `완료 n · 되돌리기`로 합니다.
- 아침 브리핑에 할 일 직접 추가: 목록 바로 아래 `할 일 추가...` 입력창에 적고 `+`(또는 Enter)를 누르면 `할 일` 줄로 더해집니다. 입력창 왼쪽의 작은 시각 pill(`input[type=time]`, 비워 두면 미지정)에서 시각을 고르면 기본 일정과 똑같이 왼쪽 노란 시각(`16:30`)·오른쪽 본문으로 보이고, 고른 시각은 지우기(`×`)로 비우거나 등록하면 자동으로 비워집니다(다음 항목에 시각이 따라붙지 않게). pill 안의 글자는 스크립트가 **24시간 `16:08` 한 줄**로 그립니다 — 아이폰이 `type=time`을 `오후 / 4:08` 두 줄로 크게 그려 pill 밖으로 잘리던 문제(2026-11-18 사진)를 없애려고, 실제 입력칸은 투명하게 pill 위를 덮어 탭하면 아이폰 기본 시간 휠만 열고 보이는 글자는 `.brief-add-time-face`(시계 아이콘 + `--:--` → 고르면 `16:08`)가 맡습니다. 시각은 `todos` 항목의 `time`(`HH:MM`)에 함께 저장되어 Gist 로 다른 기기·위젯에 그대로 넘어가고, 같은 문구를 시각만 바꿔 다시 넣으면 시각을 고칩니다. 체크하면 기존 항목과 똑같이 숨겨지고 `완료 n · 되돌리기`로 되돌아오며, 오른쪽 `×`로 지웁니다(지운 것도 토스트 `되돌리기`로 복구). 목록과 입력창은 아침 루틴이 `MORNING_BRIEF_START~END` HTML을 갈아끼워도 스크립트가 다시 그리므로 매일 남고, 내용은 이 기기 저장소와 Gist 동기화 `brief` 영역(`todos`, 지운 것은 `todoDel`)에 함께 실려 다른 기기와 id별 최신 기준으로 합쳐집니다. 날짜가 바뀐 뒤에도 남은 항목에는 `11.16 추가`처럼 더한 날을 작게 적습니다.
- `대학원·논문` → `구분: 대학원`에는 2026-11-15에 넣은 대학원 후보 5명(이준일·최희경·김복기·김선화·임지봉·윤성현)과 2026-11-17에 더한 3명 — 숙명여대 홍성수 교수(`g20261117_1`, `sub: 대학원 후보`), 강릉원주대 김지혜 교수(`g20261117_2`), 성공회대 젠더연구소·가족구성권연구소 김순남 학술연구교수(`g20261117_3`, 둘 다 `sub: 참고 학자`) — 이 있습니다. 셋 다 `kind: "대학원"`이라 `구분` 칩에서 `대학원`을 골라도 보입니다. `SEED`에 새 항목을 더하면 기기에 저장본이 있어도 화면이 뜰 때 id 기준으로 자동 병합됩니다.
