# TAPO’s archive

은유 님의 개인 스크랩 아카이브 — 학회·포럼, 대학원·논문, 기사·뉴스레터·자료, 공연·전시(2026년 기록), 책, 메모를 한 장에 모은 페이지.

- 웹 주소: https://metapokim.github.io/tapo-archive/
- 원본 파일: `index.html` (단일 파일, 외부 리소스 없이 동작)
- 히어로(모닝 브리핑 + 다가오는 일정)는 `전체` 메뉴에서만 보입니다. `학회·포럼`·`대학원·논문`·`기사·뉴스레터·자료`·`공연·전시`·`책`·`메모`를 고르면 `.hero`를 통째로 접어(스크립트가 `hidden` 지정, `[hidden]{display:none!important}`) 그 메뉴의 필터·카드 목록이 바로 시작됩니다 — PC·아이패드·아이폰 같은 규칙이고, 접힌 자리에 필터 줄을 12px 띄웁니다(`.hero[hidden] + .filters`). `다가오는 일정` 줄을 눌러 카드로 이동할 때도 히어로가 접힌 상태에서 해당 탭 전환·필터 해제·카드 스크롤·반짝임이 그대로 동작합니다. 페이지를 새로 열면 늘 `전체`로 시작하므로(카테고리는 저장하지 않음) 첫 화면에는 히어로가 보입니다.
- 다가오는 일정 카드: 데스크톱·아이패드 가로(>900px)에서 브리핑 카드와 폭·높이를 똑같이 맞추고(`1fr 1fr`, 공통 높이 `--hero-h`), 목록이 카드 하단까지 차면서 남는 만큼만 카드 안에서 스크롤합니다(스크롤바는 감춤, 끝까지 내리면 아래 흐림이 사라짐). 줄을 누르면 해당 카테고리 탭으로 바뀌고 필터를 풀어 그 카드로 스크롤·반짝임 표시하며, 캘린더에서 온 일정은 '네이버 캘린더 전용 일정' 안내만 뜨뜸니다.
- 브리핑 할 일 목록: 라벨·날씨 요약과 입력창·날씨 출처 줄은 카드에 고정되고, 가운데 할 일 목록(`.brief-scroll` — 아침 루틴 항목 + 직접 추가한 할 일)만 카드 안에서 스크롤합니다. 그래서 할 일을 여러 개 더해도 카드 높이가 늘지 않고 `다가오는 일정`과 계속 같은 높이입니다. 스크롤바는 양쪽 다 숨기고 터치·휠로만 움직입니다. 루틴이 `MORNING_BRIEF_START~END`를 갈아끼우며 `.brief-scroll` 상자를 빠뜨려도 스크립트가 목록을 다시 감싸 줍니다.
- 브리핑 카드 제목은 `TODAY'S BRIEFING`, 오른쪽 날짜는 `11월 16일 월` 형식으로 스크립트가 지금 시각(`new Date()`)을 넣어 채웁니다. 페이지를 켜 둔 채 자정을 넘겨도 다음 `00:00:01` 타이머가 날짜와 아래 발행 기준 줄(`issueLine`)을 다시 맞추고, 아이폰에서 앱을 다시 열 때(`visibilitychange`·`focus`·`pageshow`)도 한 번 더 맞춥니다. `.brief-when`의 `datetime` 속성은 브리핑을 쓴 시각 그대로 두어 완료 체크 기록의 날짜 키가 흔들리지 않습니다.
- 아침 브리핑: 각 항목 왼쪽 원형 버튼을 누르면 오늘 목록에서 사라집니다. 체크 기록은 `날짜|문구` 키로 이 기기(localStorage)와 Gist 동기화에 함께 남아 다른 기기에도 적용되고, 날짜·문구가 바뀌면 새 브리핑과 섞이지 않습니다. 되돌리기는 뜨는 토스트나 상단 `완료 n · 되돌리기`로 합니다.
- 아침 브리핑에 할 일 직접 추가: 목록 바로 아래 `할 일 추가...` 입력창에 적고 `+`(또는 Enter)를 누르면 `할 일` 줄로 더해집니다. 체크하면 기존 항목과 똑같이 숨겨지고 `완료 n · 되돌리기`로 되돌아오며, 오른쪽 `×`로 지웁니다(지운 것도 토스트 `되돌리기`로 복구). 목록과 입력창은 아침 루틴이 `MORNING_BRIEF_START~END` HTML을 갈아끼워도 스크립트가 다시 그리므로 매일 남고, 내용은 이 기기 저장소와 Gist 동기화 `brief` 영역(`todos`, 지운 것은 `todoDel`)에 함께 실려 다른 기기와 id별 최신 기준으로 합쳐집니다. 날짜가 바뀐 뒤에도 남은 항목에는 `11.16 추가`처럼 더한 날을 작게 적습니다.
- 내용 수정은 `index.html`을 고쳐 커밋·푸시하면 바로 반영됩니다.
- 메뉴 순서: 전체 · 학회·포럼 · 대학원·논문 · 기사·뉴스레터·자료 · 공연·전시 · 책 · 메모
- 카드 날짜 표시: `기사·뉴스레터·자료`·`공연·전시`·`논문` 카드는 연도를 함께 적고(`2026.11.16 월`, `2026.10`, `2025년`), `학회·포럼`·`대학원`·`책`·`메모`는 기존처럼 월·일만 적습니다.
- 바로가기: 데스크톱 사이드바 아래(백업 위)·모바일 상단 검색 아래에 `국가법령정보센터`(https://www.law.go.kr/)·`헌법재판소`(https://www.ccourt.go.kr/)·`내 블로그`(https://blog.naver.com/metaphor365) 알약 버튼 3개가 있습니다(새 창). 모바일 390px에서는 세 버튼이 한 줄에 들어가도록 글자·여백을 줄이고 화살표를 뺍니다.
- 뉴스레터: 헌법재판연구원 `세계헌법재판 조사연구`는 창간호(2013. 6.)부터 제81호(2026. 10.)까지 81건이 들어 있습니다(제1~76호는 2026-11-16에 목록에서 추가, 목차 요약은 상세 팝업의 판례 목록에서 정리).
- `기사·뉴스레터·자료` 안의 `구분` 필터: 전체 / 기사 / 뉴스레터 / 기타 자료
- `공연·전시` 안의 `구분` 필터: 전체 / 공연 / 전시 (장르가 연극·뮤지컬·콘서트·발레 등이면 공연, 전시·미술관·갤러리 등이면 전시 — 저장된 `kind`가 있으면 그 값을 먼저 씁니다)
- 로고(`TAPO’s archive`)를 누르면 새로고침됩니다. 아이폰 홈 화면 웹앱에서도 최신 `index.html`을 받도록 주소에 `?v=시각`을 붙여 다시 엽니다.
- 카드의 두 번째 링크(예: `판결문`): 항목에 `extraUrl`·`extraLabel`을 넣으면 `열기` 옆에 알약 버튼이 하나 더 붙습니다. `summary`에 줄바꿈을 넣으면 카드 안에서 줄바꿈 그대로 보이고(여러 줄 요약), 6줄을 넘는 만큼은 메모 카드와 같은 방식으로 카드 안에서만 스크롤합니다(카드 높이가 이웃 카드와 크게 벌어지지 않게).
- 2026-11-16 동성부부 위자료 판결: 별도 판결문 카드(`doc20260605_2025na10110`)를 없애고 연합뉴스 기사 카드(`n20260610_yna`) 하나로 합쳤습니다(판결 요지 + 이후 논의 ①쟁점·②입법·③비판, `판결문` 버튼). 기기에 옛 저장본이 남아 있으면 `ynaSynced20261116` 플래그로 한 번만 정리하고, 지운 판결문 카드 id는 `deleted`에 남겨 다른 기기 동기화로 다시 들어오지 않게 합니다.
- 기사 카드의 키워드 배지(`sub`): `n20260610_yna` 카드는 판결문 번호(`서울중앙지법 2025나10110 (확정)`) 대신 주제어 `가족다양성`을 씁니다. 옛 `sub`가 저장된 기기도 `ynaSub20261116` 플래그로 한 번만 바꾸고(메모·상태는 그대로), 다른 기기의 옛 사본이 되돌리지 않도록 `updatedAt`만 갱신합니다.
- PDF 등 첨부 자료는 `files/`에 두고 카드의 `열기`로 엽니다(예: `files/2025_geukwoo_report.pdf`).
- 메모: 제목(선택)·본문을 적어 저장하고, 카드의 `메모 앱으로 보내기`로 아이폰 공유 시트 → 메모 앱에 넘깁니다.
- 기기 간 동기화: 상단 ☁️ 버튼 → GitHub 토큰(`gist` 권한)과 Gist ID를 넣으면, 바뀐 내용만 비공개 Gist(`tapo-archive-sync.json`)에 자동 저장되고 다른 기기와 `updatedAt` 기준으로 합쳐집니다. 토큰은 그 기기의 브라우저(localStorage)에만 남습니다.
